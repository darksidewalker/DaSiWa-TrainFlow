Resize prep fits each image inside the selected max side without crop/morph. ANIMA supports up to 1536p. SDXL/Pony/Illustrious supports up to 1024p, with 1024p as the official recommended default. Originals move to input/; numbered images and captions are written in this dataset folder. Training uses bucketed resolutions/aspects.
